# План презентації проєкту «AutoService Desk»

1. **Титул:** AutoService Desk, Бабельський В. Т., група КІ-21.
2. **Проблема:** Непрозорість черг на СТО та потреба онлайн-бронювання.
3. **Вимоги та UX/UI:** Адаптивність, стандарти доступності WCAG AA.
4. **Архітектура:** Nginx Alpine, Docker Compose, модель C4.
5. **Тестування та якість:** Модульні та UI-тести на Python.
6. **CI/CD:** Автоматизований пайплайн перевірки коду в GitHub Actions.
7. **Безпека:** OWASP Top 10 чекліст та ліквідація техборгу.
8. **Демо:** Запуск контейнера та успішний статус GitHub Actions.
9. **Висновки та Q&A:** Плани на реліз 2.0 (БД та SMS-шлюз).
