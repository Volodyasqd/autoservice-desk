## 1. Технічний опис проєкту
- **Призначення:** Веб-сервіс для попереднього запису клієнтів на технічне обслуговування авто.
- **Стек:** HTML5/CSS3/JS, Nginx 1.25 Alpine, Docker Compose, Python 3.11 (BeautifulSoup4), GitHub Actions CI.
- **Архітектура (C4):** Клієнт звертається до порту 8080 контейнера Nginx; пайплайн GitHub Actions автоматично запускає перевірку `test_ui.py` при кожному коміті.

## 2. Відповідність критеріям семінару
- **Вимоги:** SRS специфікація, картки в Trello.
- **Контейнеризація:** `Dockerfile` та `docker-compose.yml`.
- **Тестування:** Автоматизовані UI-тести `test_ui.py`.
- **CI/CD:** Воркфлоу `.github/workflows/ci.yml` у GitHub Actions.
- **Безпека:** Аудит за OWASP Top 10 (`security-debt.md`).
- **Документація:** `README.md`, `CHANGELOG.md` (SemVer), `presentation-plan.md`.

## 3. Рефлексія
- **Вплив курсу:** Змістився фокус із простого кодування на системну інженерію — від проєктування архітектури та вимог до автоматизованого контролю якості.
- **Подальше використання:** Обов'язкове впровадження Docker для ізоляції середовищ та GitHub Actions CI для запобігання регресійним дефектам.
- **Порада на майбутнє:** Налаштовувати стандарти Git, конфігурацію CI/CD та авторизаційні токени з першого дня проєкту.
